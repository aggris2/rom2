# `.16a` sprite files

A `.16a` file is a list of frames, as a `.256` file is, in which every
pixel also says how solid it is. Fire, magic, the cursors and the
pictures of the inventory are in this format: things with a glow or a
soft outline.

Measured on every `.16a` file of the GOG release: 623 files with 2,865
frames, all in `graphics.res`. Every statement below held for every
file.

Read by `tools/import/sprite16a.c`.

## Layout

The same as [.256](256.md): a palette of 1024 bytes, the frames, and a
trailer of 4 bytes with the number of frames in its low 31 bits and the
palette mark in its top bit. All 623 files have a palette. No bytes are
left between the last frame and the trailer in any of them.

A frame starts with the same three numbers: width, height, and the
number of bytes of codes that follow. The largest frame is 640 by 268.

## Codes

The codes are 16 bits each, low byte first, where a `.256` file has 8.
A code has a kind in its top two bits and a count in the other 14.

| Top bits | Meaning |
|---|---|
| 00 | the next `count` pixels follow, 2 bytes each |
| 01 | skip `count` whole rows |
| 10 | skip `count` pixels |
| 11 | never occurs |

The count really is 14 bits: 8,094 codes have a count over 255, all of
them skips of pixels in wide frames, up to 639.

## Pixels

A pixel is 16 bits, low byte first:

| Bits | Meaning |
|---|---|
| 0 | not used, always 0 |
| 1 to 8 | the colour, an index into the palette |
| 9 to 12 | how solid the pixel is, from 1 to 15 |
| 13 to 15 | not used, always 0 |

Skipped pixels are not there at all. A pixel that is there is never of
solidness 0. Of the 2,845,473 pixels, 1,867,727 are fully solid, 15, and
the other 977,746 are spread over 1 to 14.

Unlike in a `.256` file, index 0 is a colour like any other: 32,455
pixels have it.

Measured over all 2,865 frames:

- Every frame's codes add up to exactly `width * height` pixels and use
  exactly the bytes the frame says.
- No run of pixels crosses the end of a row.

This reading was checked by drawing: a dagger from the inventory, a
fire bolt, a cursor and a flash of lightning come out in their colours,
and the lightning fades from frame to frame.

## Not known

- How the game mixes a pixel of solidness 1 to 14 with what is behind
  it: whether 15 levels are spread evenly, and whether fire is added to
  the background rather than laid over it.
- The `.16` format of the fonts, which is related and not yet read.
